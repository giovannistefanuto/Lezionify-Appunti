# 📚 Lezionify · Lezioni universitarie

Un archivio di lezioni organizzato per corso e **data della lezione**, con dispense in italiano, traduzioni in inglese e trascrizioni grezze.

## Come consultare le lezioni

1. Scegli un corso nella tabella qui sotto.
2. Cerca la data: le lezioni sono ordinate dalla più vecchia alla più recente.
3. Apri **Italiano** per la dispensa, **English** per la traduzione o **Trascrizione** per il testo grezzo.

Puoi leggere i file Markdown direttamente su GitHub, senza installare nulla e senza chiavi API. Per consultarli offline, usa **Code → Download ZIP** oppure clona il repository. Le cartelle usano il formato `AAAA-MM-GG`; se una giornata contiene più lezioni, il titolo distingue i materiali. Una traduzione non ancora disponibile è indicata nella tabella e verrà aggiunta quando sarà generata nell’app.

## Che cos’è Lezionify

[Lezionify](https://github.com/giovannistefanuto/Lezionify) è un progetto personale nato per semplificare lo studio universitario: un’app desktop Electron, React e TypeScript che organizza registrazioni, trascrizioni e dispense in un archivio locale ricercabile. L’autore definisce le idee e le scelte del prodotto e usa strumenti AI come supporto allo sviluppo e alla rielaborazione dei materiali.

### Dall’audio alla lettura

Registrazione → importazione locale → trascrizione grezza → dispensa italiana → traduzione inglese → sincronizzazione GitHub abilitata dall’autore.

Gli audio originali restano nell’archivio locale. Questo repository contiene i testi selezionati dalla sincronizzazione; le chiavi API e le credenziali non vengono pubblicate. La sincronizzazione aggiorna anche le lezioni corrette e le traduzioni aggiunte successivamente.

## Usare i materiali per studiare

Le dispense e le traduzioni sono elaborate con AI e possono contenere errori: confrontale con la trascrizione, le slide e le fonti del corso, soprattutto per formule e termini tecnici. La trascrizione è il testo grezzo prodotto dal flusso di trascrizione e può a sua volta richiedere correzioni. Questi appunti personali non sostituiscono il materiale ufficiale del docente.
